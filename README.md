# Group-3-Project
This repository contains our Group 3 project for Fundamentals of Computing.

## Project Overview
We were tasked with benchmarking a website based on John Hopkins Hospital. Each team member took responsibility for building and styling an equal number of web pages, while conducting research to ensure the site felt professional and consistent.

## Collaboration
- We gathered regularly to discuss a uniform site style.
- We agreed on consistent header and footer design across pages.
- We divided the web pages equally so everyone contributed to the project structure.

## Work Process
- Each member researched hospital website design and user experience best practices.
- We reviewed each others pages to keep the look and feel consistent.
- The final product includes shared layout elements and a cohesive navigation experience.

## AI Assistance
A bit of AI support was used to enhance our work:
- to help explain Git commands we did not understand,
- to help fix and improve page content,
- to help refine the design and functionality of the website.

## Notes
This project reflects our groups efforts to combine research, collaboration, and web development skills into a polished benchmark website.
